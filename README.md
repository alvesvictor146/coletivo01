# DESTINA — Transporte Brasília ↔ Chapada dos Veadeiros

Site oficial do serviço **DESTINA**, conectando Brasília a Alto Paraíso, São Jorge e Cavalcante na Chapada dos Veadeiros.

## 🚀 Tecnologias

- [React 18](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide Icons](https://lucide.dev/)

## 🌿 Funcionalidades

- **Itinerários e Tarifas**: Tabela de preços para transporte compartilhado, privativo e caminhonetes para Alto Paraíso, São Jorge e Cavalcante.
- **Integração WhatsApp**: Mensagens pré-formatadas para solicitação de reserva e consulta de disponibilidade.
- **Galeria dos Principais Atrativos**: Fotos e resumos dos cartões-postais da Chapada.
- **FAQ Interativo**: Respostas para as principais dúvidas de horários, bagagens e operações.
- **Frotas para Grupos**: Opções sob medida com Vans e Ônibus executivo.
- **Pontos de Embarque em Brasília**: Aeroporto, Rodoviária Interestadual, Plano Piloto e regiões centrais.
- **Design Responsivo**: Adaptado para celulares, tablets e desktops com modo escuro e estética inspirada no Cerrado.

## 🛠️ Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/alvesvictor146/coletivo01.git
cd coletivo01
```

2. Instale as dependências:
```bash
npm install
```

3. Execute o servidor de desenvolvimento:
```bash
npm run dev
```

4. Para gerar a versão de produção:
```bash
npm run build
```
